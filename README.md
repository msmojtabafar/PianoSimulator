# 🎹 Piano Simulator

A real-time piano simulator developed in C++ for Linux, designed to provide a responsive and low-latency virtual piano experience using a computer keyboard.

## ✨ Features

* 🎹 Real-time piano keyboard simulation
* ⌨️ Computer keyboard control
* 🔊 Real-time audio playback
* ⚡ Low-latency audio processing
* 🎵 Multiple piano notes
* 🎚️ Configurable audio settings
* 🖥️ Linux support
* 🧩 Modular and extensible architecture

## 🛠️ Technologies

* **C++**
* **Linux**
* **PipeWire**
* **ALSA / Audio subsystem**
* **CMake / Make**
* **Git & GitHub**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/PianoSimulator.git
cd PianoSimulator
```

### 2. Build the project

Follow the build instructions provided by the project source and make sure the required development dependencies are installed.

### 3. Run

After building the project, start the piano simulator:

```bash
./PianoSimulator
```

> The exact build and execution commands may change as the project develops.

## 🔊 Audio

The simulator uses the Linux audio stack for real-time sound playback.

For the best experience, a properly configured PipeWire audio environment is recommended.

## 🎹 Controls

The computer keyboard is used to play piano notes.

The keyboard mapping may be expanded and customized as development continues.
